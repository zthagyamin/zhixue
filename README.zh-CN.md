# 知学 · Zhixue

**把自己的笔记变成练习、反馈和每天能继续的复习。**

[English](README.md) · [在线网站](https://zhixue-daily.zthagyamin.chatgpt.site/) · [开始使用](docs/zh-CN/getting-started.md) · [常见问题](docs/zh-CN/FAQ.md)

知学是面向课程学习、词汇、编程、数学与论文阅读的学习工作台。它把选定的个人材料连接到练习中，保留实际作答证据，帮助你重新练习薄弱点。原始资料仍由你的 Obsidian 知识库或已连接来源管理，网站提供学习交互。

**公开测试版 · 源码基线 1.41.1。** 工程检查和隔离浏览器测试不等于已经证明教学效果，也不代表 AI 能可靠评判任意材料。在线网站可能独立更新，请以页面显示的版本为准。

## 从一小份材料开始

1. 打开[学习工作台](https://zhixue-daily.zthagyamin.chatgpt.site/study)，需要时按提示登录。
2. 在“用自己的笔记试学”选择一小份 Markdown/TXT，或粘贴一个完整段落。
3. 先自己回答，再查看原文，重练标记为不熟悉的题。
4. 按需把材料保存到当前浏览器。需要持续读取来源和本机写回时，再连接 Companion。

首次笔记试学不需要 Companion 或 AI 密钥。试学答案是临时输入；保存材料是单独操作，不会产生正式学习成绩。

## 能做什么

| 领域 | 当前源码包含 | 使用边界 |
| --- | --- | --- |
| 每日学习 | 长线安排、分组练习、复习队列和进度 | 需要已登记内容及相应设置；耗时估算仍需真实使用校准。 |
| 词汇 | 分阶段新学、到期快速复习、拼写与兼容闪卡模式 | 具体行为取决于词卡内容与模式。 |
| 课程练习 | 有来源的回忆、单选/多选、反馈和原页补练 | AI 可以无法判定；“待核对”不等于答对或答错。 |
| 编程 | Python 题目执行、公开案例反馈、提示与原页修正 | 通过所给测试不代表完整正确；本版不承诺 C/C++ 生产执行。 |
| 数学 | 有界数值/符号核对、可选步骤核对和支持的相关练习 | 不覆盖任意证明和任意表达式；不支持的答案可保持待核对。 |
| 论文阅读 | PDF/文本阅读、笔记、选区工具和支持的图表引用 | 提取质量不一；扫描件、复杂布局与原文一致性需要人工核对。 |

课程、编程、计算与论文流程均是**测试版能力**。真实材料、模型质量、手机硬件、跨设备学习与学习效果仍需验证，见[路线图](docs/zh-CN/roadmap.md)。

## 数据在哪里

“原始来源在本地”不代表所有功能都离线，也不代表所有摘录永远不离开设备。

| 部分 | 职责与边界 |
| --- | --- |
| 原始资料 | 本地文件保留在选定位置；Notion 本身是外部服务。连接资料不改变资料归属。 |
| 浏览器笔记试学 | 在当前页面读取所选文本，不上传、不调用 AI。显式保存的试学材料留在当前浏览器；离开或刷新后不保留试学答案。 |
| Companion | 在 Windows 本机处理已授权来源读取、配对及支持的写回；本地来源映射和本机凭据在电脑端管理。 |
| 账号功能 | 启用后，结构化题目、学习事件及安排/进度会使用账号隔离的云端服务；支持的功能另有浏览器/本机副本。题目内容可能包含从笔记提取的文字。 |
| AI | 启用后会向所选 API 提供商发送问题、相关上下文或回答。本机模式密钥使用系统凭据库；另行配置的账号模式密钥加密保存在账号服务。调用可能产生费用。 |

启用前预览来源，不接入无权处理的材料。使用云端或 AI 功能前，请阅读[常见问题](docs/zh-CN/FAQ.md)及当前页面设置。

## 平台与托管

- 网页提供桌面与窄屏布局；响应式布局不等于所有真实设备均已验收。
- 已支持的打包 Companion 流程面向 **Windows x64**；测试版不承诺 macOS/Linux 安装器。
- 手机和平板可使用支持的浏览器/账号功能，不能运行 Windows Companion。首次资料登记和本机写回可能需要已连接的 Windows 电脑。
- 现有在线服务依赖 **OpenAI Sites 身份与 Cloudflare D1**。下载源码不包含托管凭据、生产账号，也不等于已有完整的跨平台自托管方案。
- 离线能力取决于具体功能。云端同步、API 判题，以及通过已关闭 Companion 读取资料，不会因为曾经打开页面而自动继续。

现有网站的[Companion 指南](https://zhixue-daily.zthagyamin.chatgpt.site/companion-guide)说明 Windows 设置。本源码仓库不附带或认证经过独立开源分发审查的二进制发行包；有正式包时请核对对应版本说明与校验值。
