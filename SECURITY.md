# Security policy / 安全政策

## Supported scope

This public beta accepts reports about the latest public source and the maintained hosted service. Older snapshots are not promised security support. A source fix, a website deployment and a Companion installation are separate deliveries.

Use **GitHub private vulnerability reporting** on this repository: [Report a vulnerability](https://github.com/zthagyamin/zhixue/security/advisories/new). If that channel is unavailable, open an issue that only requests a private contact route; do not include vulnerability details, credentials or personal learning data.

Provide a minimal reproduction, affected version/commit, expected and observed behavior, and impact using synthetic material. Never test other users' accounts, extract data or weaken protections. There is no promised response SLA or bounty program.

## 中文

安全报告范围为最新公开源码和维护中的官网。旧快照不承诺安全维护；源码修复、网站上线和 Companion 安装分别验收。

请使用本仓库的 [私密漏洞报告](https://github.com/zthagyamin/zhixue/security/advisories/new)。入口不可用时，只提交“请求私密联系渠道”的公开问题，不附漏洞详情、凭据或个人学习内容。

报告包含最小复现、版本/提交、预期与实际表现、影响；使用合成资料，不测试他人账号、不提取数据、不弱化保护。本项目暂不承诺响应时限或漏洞奖金。
