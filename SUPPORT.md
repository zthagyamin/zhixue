# Support / 支持

Read [English FAQ](docs/en/FAQ.md) / [中文常见问题](docs/zh-CN/FAQ.md) and the development guide first.

For bugs, use the bug-report form with a version, reproduction, expected result and sanitized logs. Feature requests should describe the learning problem and a concrete example before proposing controls. Security reports follow [SECURITY.md](SECURITY.md).

维护者通过 GitHub Issues 提供尽力而为的支持；没有承诺 24 小时服务、商业 SLA 或已建立的外部社区。报告前请移除笔记原文、作答、配对码、密钥、账号标识和私人路径。不要上传完整知识库或日志目录。
