# ADR-002：即时补练与正式作答分离

状态：第二阶段实现决策。范围：内部页面接口和候选源材料，不修改正式题目/事件协议。

即时补练使用独立临时草稿端口，没有 onGrade、事件写入或 FSRS 端口。宿主可登记子草稿的脏状态，使已有导航/关闭保护继续生效；父作答保存后冻结，子草稿不能修改父字段。父作用域清理使子草稿和在途执行失效。

回忆若需先保存首次结果，沿用既有延迟反馈回执；保存确认后才进入补练。补练结束只返回同一反馈，不重新提交。选择/编程在原结果已确定的情况下展开辅助练习，最终正式提交仍使用原结果。

局部核对只引用已有参考。不把自动从一句原文改写的题目标为已核验，不补造反例的标准答案。新的反例/辨析题必须由用户核对材料后才能使用；没有材料时提供无自动评分的反思或继续入口。

拆卡与论文复测候选是源材料编辑工作流：先校验来源定位和版本，再由用户核对题目、参考、内容属性及新增负担。批准不等于掌握；保存不等于已经排入今天。通过 ADR-003 的专用候选文件和既有来源预览/导入确认流程接入，不能借旧内容哈希提交新题成绩。

临时输入离开后不保留。导出只表示已准备本地文件，不显示已入库；同一文件在同一来源的重复导入保留稳定身份，来源内容改变则产生新身份。原文、模型调用、沙箱权限、旧成绩和调度政策保持原约束。
