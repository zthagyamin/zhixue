# ADR-003：候选采用无损、独立版本化的来源格式

第二阶段的导出不能通过普通 Markdown 表格传递数学符号、竖线和多行参考；既有导入器不还原实体编码。因此采用专用 `.zhixue-candidates.json` 文件，`documentType=zhixue-practice-candidates`、`schemaVersion=1`，严格校验状态、父项、内容属性、引用范围和大小。

只识别这个专用后缀，不把通用 JSON 配置文件纳入文件夹或 ZIP 的资料扫描。旧客户端不支持时拒绝导入，不能改名为普通文本绕过；网站明确提示需包含该能力的新 Companion。未知版本或未知字段均拒绝。

格式包含用户核对的候选，不是正式学习事件。导入仍经过既有“预览→确认接入→计划确认”流程，生成新的内容身份；父项与来源声明保留在生成的原始材料中，不能借用父项哈希写新题成绩。来源版本是提供者声明，导入器不伪称已重新验证外部原文件。

引用偏移使用 UTF-16 code units，与浏览器选择器一致；格式回环测试覆盖比较符、竖线、多行与非 BMP 字符。没有修改原有题目/成绩协议、数据库表、沙箱权限、历史记录或已发布安装包。
