# ADR-004：规则模板、数学步骤与即时重练

状态：第三阶段实现设计。范围：页面临时实例、旧接口保守修正，不升级旧正式内容/事件协议。

选择有限、可独立计算的模板而非任意文本改写或自由模型出题。模板版本与参数域共同定义题意；实例绑定 parentItemKey、parentContentHash、hashKind、模板版本、seed、parameters 和 variantHash。父内容无权威哈希时只能称可见材料快照，不能冒充内容发布身份。新题不复用旧哈希提交成绩。

用户在当前计算题反馈中选择模板、确认相关性后展开。四个首批模板是基础代数原型；内置模板的规则验证不等于教师人工审定、语义保留集或学习效果验证。题目和答案均可在客户端获取，不宣传防作弊。

分步训练核对方法选择、题目声明的适用条件、限定局部表达式。规则和定义域显式绑定；有界内核只负责其支持的表达式等价，不用少量数值采样证明恒等式。最终答案和步骤状态分开呈现；不支持的函数/步骤为 unknown。展开步骤、查看参考、重试均属于本页辅助过程，不产生正式事件。

旧 /practice/variant 保留原响应外形以兼容旧调用者，但计算题不再乘答案并拼接题干；结构化选项保持原配置。网页将旧操作改称重排复习/原题再练，只接受同一内容身份和同一答案的允许呈现变化。再次作答只更新本页练习状态，不调用正式记录回调，不修正第一次结果统计；提示持久化范围也不能沿用原作答。

开发夹具按题族标识检查划分污染，当前已用于开发的材料不得改称未见保留集。正式题库候选发布仍使用单独批准链；本阶段不自动发布生成题，也不安排额外每日负担。
