# ADR-005：共享正式作答生命周期

状态：M2 候选实现，验证与集成状态以对应 PR 为准。正式事件和持久提交日志的格式保持原样。

两类宿主共享 `StudyAttemptSession`。宿主负责可信输入、原有存储/投影/同步实现；用例负责接受、固定身份、不可变捕获、保存失败/本机已保存的区分和一次性继续。没有把整个 Dashboard 当服务传入，也不再各写一套生命周期。

请求在草稿锁接受时取得注入的 ID 与时间。首次捕获的命令与提交帧只能读取副本，重试不重新计算旧事件的时间、FSRS 输入或辅助观察。同一未完成请求如果换等级/模式，明确拒绝冲突，不复用身份覆盖内容。旧正式事件 V3 无新增字段；内部记录调用可使用该固定身份，旧调用者继续使用原默认身份创建方式。

本机持久成功是继续的门槛，同步不是门槛。持久回调一旦确认，后续投影/视图异常只能提示已保存，不能解冻并生成另一份成绩。继续回调只能消费一次，并仍检查宿主/视图作用域；关闭页面只撤销显示资格，不宣称撤回已经开始的数据库写入。

草稿内容与临时补练仍在页面内；成功清理、显式取消和换库清理区分，避免 commit 清理反过来取消它自己的成功回调。未知或迟到回执不能清除新一代草稿。读写日志继续走既有完整校验和幂等持久链，不以弱本地缓存推断保存成功。

评级上限与辅助观察是纯规则，迁入 domain/assessment 并保留兼容导出。三阶段、回忆单遍及即时重练的策略不变。完整宿主回归和公开应用 API 测试同时保留；没有把工程测试当作学习效果验证。

命令不捕获页面轮次或下一题位置。失败期间或延后继续期间，其他题可能已有新进度；宿主从已有同步轮次存储读取当前状态，核对轮次作用域、题目顺序和显示资格，再合并已保存题。切换页面后继续仍读当前轮次。正式事件始终保留首次接受的阶段和调度输入。

分组草稿另保留原内容 sourceItem。显式重置原题会清其各分组草稿，并用 source epoch 使尚未物化的旧 adapter 失效；成功提交仅清当前分组条目，其他内容输入保留。这是页面缓冲契约，不新增正式事件字段。

验收边界：公开 API 测试覆盖重复提交、回执丢失、保存后异常、作用域变化和取消；真实持久日志回归覆盖本机和账号。新增 CI 浏览器直接挂载 `SubjectView`、`PracticeSession`，使用真实 IndexedDB、合成判题和受控传输。内联浏览器的持久适配器是夹具，生产 Dashboard 适配器另有实际回调回归；原完整应用账号场景继续执行。结果不代表真实模型准确率、线上个人资料或手机硬件验收。
