# ADR-007：来源连接与同步用例

状态：M4 实现设计，完成状态以实际候选 PR 的验证结果为准。

来源连接负责“当前可见资料来自哪里、何时允许替换”；同步负责“已经保存的哪条事实发往哪个目标、得到了什么回执”。二者共享宿主提供的用户/库/模式资格，不能通过当前页面反推历史记录的发送目标。

采用 application 中的明确用例与带范围的操作会话，domain 中保留不可变提交、字段校验和回执契约，features 只管理 React 绑定与调度触发，infrastructure 实现传输等平台操作。旧 app 存储与来源投影作为迁移期适配器，禁止把整个页面控制器重命名成服务。

发送已经得到的持久回执继续归属于原用户、原记录、原目标；切页面仅撤销显示资格，不伪造失败、成功或回滚。新范围有自己的请求锁，旧请求不能阻塞它。辅助摘要依赖原事件已接收，目标之间独立失败/重试；旧活动/旧云队列不合成为新的 V3 作答。

来源应用先核对版本与完整历史，再处理冻结与发布。进行中的练习保留已确认题面/进度；新来源暂存。切库/切模式需准备新来源后才原子替换，异常保留旧可用来源。取消后台请求与真正失败分开，清理可重建缓存不能删除恢复所需的数据。

维持既有协议、哈希、正式成绩、FSRS 与数据库格式。本阶段不包含生产部署、数据迁移、用户安装或 M5 后端边界拆分。新增格式或调度语义变化必须另立方案；回滚一起撤回用例和装配，不删除学习历史。
