# ADR-010：明确回忆自评与按需论文补练

状态：采用；2026-09-20按用户反馈简化交互，工程验收和发布身份以交付记录为准。

## 目标与选择

用户报告AI回忆反馈的三个选项没有反应，并明确选择仅让“部分记得/不记得”的论文知识点进入后两阶段。采用“首轮回忆 → 看要点 → 简短重答”；答好的题可以直接继续。用户进一步明确：保留简短回答，去掉弹窗、核对表、勾选确认和大段说明。

Jev仅辅助本次方案判断，没有接入学生判分或网站运行时。一次合批包含两个独立问题，实际返回偏向明确区分只读AI结果与人工自评，以及按需三阶段；用户最终确认后者。模型概率不代表学习效果或权限批准。

## 边界与兼容

- AI建议显示为结果，通过“改用我的自评”进入真正可选择的三档输入。已有AI反馈保留，不把修改按钮禁用后伪装成可编辑。
- 已保存结果不再展示冻结的自评控件。明确忘记、提示上限、成绩保存与重试的既有规则保持。
- 论文范围只认已有paper领域或明确的旧论文核心观点来源标签，不从任意题干猜分类；普通回忆继续现有通用补练。
- 沿用原保存回执与TemporaryDraft。首轮保存成功后才开放补练；保存失败、换题或换学习空间时，不允许串用旧输入。
- 新视图只有临时输入端口，不拥有正式作答、评分、FSRS或持久化端口。补练次数不增加正式记录，也不取消稍后的计划复习。
- 要点只来自已有参考，不要求用户填写观点、依据和边界。重答时整张卡片替换原反馈，参考与原回答不留在底层页面。
- 同一张卡片只在看要点、简短回答和对照答案之间切换；每步最多两个主要按钮。“记住了”消费首轮保存回执直接继续；“再来一遍”清空本次重答，重新看要点。没有额外完成页。
- 临时输入仍受换题、换空间和离开保护约束；正常练习不弹确认，主动离开未完成输入才提示。
- 不新增数据协议或迁移，不改变原文、内容身份、题组遍历和成绩统计。

## 验收与回滚

覆盖AI三档、人工三档切换、提示封顶、忘记、保存失败/重试、先保存再补练、无参考、失效草稿、闭卷时参考隐藏、重复补练清空与不新增正式记录。真实浏览器覆盖桌面与390px、深浅主题；不拿仅渲染测试冒充交互验收。

简化层的回滚仅涉及视图和临时会话控制，原正式事件和复习安排不需要清理。即时重述完成不等于长期掌握；未见题集、人工语义与延迟学习收益仍需单独评测。
