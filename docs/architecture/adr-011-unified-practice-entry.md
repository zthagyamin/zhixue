# ADR-011：所有学科入口使用同一练习分组

状态：采用。适用于今日任务、今日下方的学科卡片、顶部学科菜单及学习中的切换学科。

## 问题与证据

同一份计划的每词复习仍是独立、不可变的调度任务。今日任务入口已经将这些任务组合为可连续练习的一组；学科入口却直接把任务列表转为旧版逐任务适配器。词汇视图随后选择第一条，因此多词复习显示为一词一组，甚至先进入已完成的单词结束页。相同来源在两个入口显示不同范围，不能靠给某个插件修改默认数量解决。

## 决定

- 学科入口由 `application/planning` 的 `startSubject` 调用与今日开始/继续相同的分组、来源校验、保存及进度恢复路径。Dashboard 仅连接入口与端口。
- 分组仍按学科、任务类别、实际练习方式组织；同题不同复习轮次不借用完成结果。三阶段、拼写、闪卡、回忆、单选、计算、代码及论文类型共享分组能力。论文精读工坊仍使用自己的资料工作流，不生成虚假的评分任务。
- 优先继续本学科未完成或已开始的组；全部完成时显示整组回顾。新学与到期复习不混合。
- 每日目标和用户追加的范围保持不变。已有任务但被目标暂缓时明确提示追加，不自动转为自由练习；阻塞任务保留来源核对要求。
- 账号学科入口复用同账号、同学习库、同日已验证计划，与点击具体今日任务一致，不新增强制联网步骤。没有可用计划时显示恢复入口，由用户选择缓存自由学习。后台计划后来就绪，也必须从统一入口继续，不能落入旧单任务适配。
- 原任务、学习事件、保存回执、FSRS 和新词计数不迁移、不重写。没有计划任务的学科可进入明确标注的自由学习。

## 后续更新规则

新增插件或导航入口必须接入共享分组。不能把 `DailyTask` 的单条调度粒度当作用户可见的一组；不能只修页面标题或硬塞未到期内容凑数量。验证至少包含多项同类、不同方式/新学复习隔离、部分完成续练、日目标、来源阻塞、离线恢复和切换期间迟到结果。

## 验证与回滚

测试涵盖八种插件的实际路由与多项分组、账号/本机入口、完成/暂缓/取消及缓存恢复。浏览器使用合成账号验收词组、阶段推进、返回续练、回忆题组和学科菜单；真实生产页仅用于观察入口问题，未替用户作答。

回滚本次入口、用例与适配器改动即可，无数据迁移或 Companion 安装变更。
