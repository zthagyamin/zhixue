# ADR-012：具体回忆题与阅读材料分开处理

状态：采用。

## 问题

旧生成器在没有明确题干时，会把结果卡标题套入“回忆核心要点，并说明相关概念、依据或适用条件”的模板。这个标题提示并没有限定要回答什么，却与正常题目一起进入自测和判分。

## 规则与范围

- 默认复习必须有明确问题及可核对参考。原文自带的问题可沿用；只有标题或陈述、无法确定问题时，生成只读材料标识，不猜测知识点、不拼凑标准答案。
- 本轮确定性校验识别旧生成器的已知泛化模板及新只读标识，不宣称可以自动判定所有自然语言题目的教学质量。任意作者题面的单一检查点、事实准确性仍需内容审定。
- 网页对旧 Companion 已同步的模板题立即执行同样规则；材料保留可读，原题、内容身份和已有事件不被改写。新生成的题面变化由既有内容版本机制处理。
- 本机、账号、确认开始、每日目标、续练和旧版练习队列共用可练条件。任务内按条目筛选，不能因一个模糊题丢掉同任务中的有效题；正式任务完成条件保持原始成员。
- 暂缓材料用独立的 withheld 导航集合表示，绝不伪装成已完成。全部到期数与可自测数分开标注，追加也只加入具备出题条件的内容。
- 切换到闪卡等显示方式不能绕过原题质量；阅读材料没有评分控件。原始参考可来自答案、解析或既有 learningSupport 的要点/完整提示。
- 云端与 Companion 判题在调用模型前拒绝已知模糊模板。参考中的背景信息不应被当作题干额外要求的答案点。模型质量和学习效果另行评测。

## 兼容与交付

不改变计划、事件、账号内容的持久化协议，不删除笔记或历史。现有已批准计划原样保留，网页只改变默认可执行队列；无效材料仍属于资料范围。论文简短回答与按需再练流程保持。

网站发布立即覆盖旧题的筛选与显示。仓库同时更新 Python 生成器和判题前置检查；本次不冒充已升级用户本机 Companion，也不替换现有版本安装包。原始笔记只读，索引不会为了找题扩展扫描范围。

## 回归与回滚

需覆盖旧/新标识与TS/Python一致性、明确问题保留、混合任务、异常字段、参考不丢失、每日目标填充、确认开始、插件切换和无模型调用。使用合成账号验证默认队列及材料阅读；不写用户学习成绩。

可回滚本轮代码与派生导航规则，无数据迁移。旧事件继续按其原始语义展示。
