# ADR-013：学习结果摘记与可练问题分开，论文方法题带明确上下文

状态：采用。

## 问题

ADR-012只拦固定泛化模板仍不够。自动生成器把“区分/解释”等能力描述截成题目，因此保留下来的题既缺少明确论文身份，又可能把过度概括的旧摘记当标准答案。学习结果卡的reviewPoints还可能包含学习过程备注，不能自动等同于经过审定的题库。

## 决定

1. 学习结果卡缺少独立、显式问答素材时只作阅读材料，停止按动词或问号自动推断“合格问题”。既有明确题库问答继续可练。
2. 兼容识别两代自动格式：旧“请闭卷解释”复制全文，以及“请闭卷回答”复制第一分句。只有全部非空参考都符合已知复制关系时才迁移；存在独立答案/解析时保留显式题，不做模糊匹配。
3. 迁移只改变可执行性和显示，不改存储内容、哈希或旧成绩。原摘记显示使用独立读取函数，不能用评分时的echo过滤让材料消失。原摘记仍需核对，不冒充已核验标准答案。
4. 初练与补练显示题目自己的来源说明。资料库总标题不能代替论文身份；来源说明变化会使旧答题上下文失效，云端判题同样收到当前题目来源。
5. 论文复习以方法理解和应用变式为主，少量实验判断辅助。每题应有论文名、位置、明确条件和一个可核对的核心检查点；变式不得冒充论文原实验。具体内容须审读原论文，工程测试不能证明教学质量。
6. 新题采用独立内容身份，保留原题与历史，不继承旧掌握状态。候选文件先做内容预览与校验；正式论文题库登记为独立的 `domain: paper` 固定索引学科，逐题提供来源，避免通用文件入口误归为课程。每日计划仍需原有确认。

## 内容验收示例

- 明确论文与条件：ResNet identity shortcut，限定相加处，给定目标x+0.1x，问残差分支输出。
- 解释具体机制：AlexNet Dropout如何减少对固定搭档神经元的依赖。
- 变式要说清假设：空间尺寸不变、64到128通道时Option A如何补齐。
- 拒绝抽象任务：只要求“区分论文声明与因果推断”，未提供论文或具体结论。

## 验证、兼容和回滚

回归覆盖旧自动题、独立答案保护、原摘记可读、TS/Python一致性、初练/补练来源与来源变化；浏览器用合成数据验收。原始论文、笔记及正式学习状态保持不变，不因内容审定生成学习成绩。

可回滚网页/生成器改动，不需要数据迁移。新题通过独立来源接入，可停用该来源而保留历史。用户本机程序未被自动升级，网页对旧同步题兼容处理。
