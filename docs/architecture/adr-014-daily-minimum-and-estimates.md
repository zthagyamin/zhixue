# ADR-014：最低新学目标与参考耗时分开

状态：采用。旧版本继续按原上限与预算解释，旧计划不静默改写。

用户要求每天至少学术新词20个、口语新词5个；未经校准的固定耗时不能自动把目标压缩为2个。

## 契约与兼容

- 学科新增可选 `dailyMinimumTarget`，原 `dailyQuotaTarget` 继续表示上限；最低值不得大于上限。
- 长线设置新增 `timeBudgetMode: advisory | limit`，缺省保持旧版limit。新建词量优先目标采用advisory；旧目标通过显式转换并预览、保存后生效。
- advisory先分配最低数量，固定估时不截断最低量；弹性内容仍参考余量。超出参考预算与可用材料不足明确提示，不伪造学习完成。
- 缓冲日保留最低量，只停止弹性加学。没有最低量的旧缓冲日保持原行为。
- 保留既有每日分配协议，不增加Companion写回所需字段。长线TS/Python验证维持一致；不自动升级用户本机程序。
- 今天的调整为显式草稿操作，优先保留已完成、已开始、手动锁定内容；新旧计划均经既有确认与来源校验。默认长线编辑继续从明天生效。
- 未收集可靠有效耗时前显示“用时待估”，固定分钟仅在估算依据中展示。本阶段不声称具备个人耗时模型。

## 实施与验收

1. 领域回归先复现20+5被预算截断；实现最低量与兼容校验、缓冲日及不足提示。
2. 表单明确最低量/上限/参考预算；首页区分整日与下一组，草稿显示学科名。
3. 显式重新核对今天最低词量，扣除当天已学且保留进行中与完成项；并发/来源变化取消不得污染草稿。
4. 相关回归、完整项目检查、独立审查与隔离浏览器验收；按授权正常发布。个人计划不自动批准。

回滚：旧计划无需转换；已保存新模式只能用支持此模式的校验器读取，不回退到旧算法重新解释已确认最低量。网站回滚前保留新模式数据并显式告知兼容限制，不改历史成绩。

## 已验证

Node完整检查2368/2368；Python725项中724通过、1项符号链接权限跳过。独立复核No findings。合成浏览器完成旧上限转换、未来生效日预览、保存、今日2+2补成20+5的未批准草稿，及390/1440深浅主题。没有产生真实学习成绩。
