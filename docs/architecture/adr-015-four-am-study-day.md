# ADR-015：北京时间凌晨四点切换学习日

状态：实现与候选验收完成，待配套发布及用户安装。

## 行为与历史

- 每个学习日结束于次日04:00（Asia/Shanghai）。实际事件UTC时间和FSRS到期instant不变，AI费用日限额继续按自然日。
- 本次已跨过2026-09-22午夜。为避免日期倒退，从2026-09-22 04:00启用新政策；此前记录保留旧日期。过渡学习日09-22为午夜至09-23 04:00，共28小时，不能用固定24小时构造它。
- v1任务事件原有day字段及hash不可重写。读取兼容其原自然日声明，也接受新学习日声明；计划归属仍绑定其已保存的day/planHash，不把声明随当前偏好重算。
- 新事件使用新学习日。既有Companion1.38会拒绝部分凌晨任务事件，需要升级兼容程序后启用完整同步，不能声称仅发布网页就完成。
- 日期字符串是已经声明的日期，直接验证；禁止把日期补成午夜timestamp后再次偏移。
- 来源笔记的纯日期复习在该学习日起点可用；真正的FSRS到期timestamp不移动。旧来源日期规范午夜表示仅在来源复习适配处转换，保留原始证据hash。

## 验收

共享TS/Python向量覆盖旧凌晨、过渡日、03:59:59.999/04:00、跨月/跨年、非法日期，旧/新任务事件混读及hash不变。端到端覆盖新词统计、今日窗口、练习恢复、日期型复习与真实due instant，以及Companion同步与配置数据保留。
