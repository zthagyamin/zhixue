# ADR-016：到期单词先做一次闭卷自评

状态：候选实现与合成验收完成，待代码合入及网站发布。

## 用户行为

今日计划中的到期三阶段单词，先显示原第三阶段的闭卷词义自评。记得时，这个词的本轮复习即可结束；忘记时，保存失败记录后立刻回到第一阶段，并按现有三阶段完成补练。新词、自由学习和额外巩固仍从各自原有阶段开始。已开始的复习轮次按已保存阶段继续，不重新跳到闭卷自评。

## 证据与兼容

首次闭卷复习只是一轮单步自评，采用已有 `flashcard` 记录模式：真实事件为 `stageBefore=0`，记得时 `stageAfter=3`，忘记时 `stageAfter=0`。显示第三阶段不代表前两阶段已有作答。忘记后的补练使用已有 `three-stage` 事件链，从 `0→1→2→3`，不得补造中间作答。每次正式评分都等原始事件保存成功后才更新页面；FSRS 只根据实际自评和补练末阶段更新。

账号与本机仍使用原有 v3 作答事件、记录封套及签名规则；不重写旧记录，也不要求 Companion 升级。旧版客户端的完整三阶段记录继续兼容。复习组由现有计划的 review 类别标识，不能仅凭词汇学科或到期时间推测。复习起点须由当前轮次的已保存事件确定；上次忘记且尚未补练完成时，继续从第一阶段。

## 回滚和验收

回滚仅改变新复习卡的入口；已经保存的单步复习和三阶段补练都保留，FSRS 到期时间和正式作答不修改。验收涵盖正常新词、首次到期词、记得、忘记、跨页与跨日恢复、多词同组、账号记录链、本机记录与错误/重试路径；工程测试不等于真实学习效果。
