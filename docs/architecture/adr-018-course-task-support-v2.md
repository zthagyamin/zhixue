# ADR-018：课程任务内容 V2

状态：2A采用；2B诊断与存储另行版本化，不冒充已实现。

## 原因与决定

V1只有题面、参考/要点、提示与选项陷阱，缺少单一能力、来源片段和已核验补练映射。新增Recall/Quiz LearningSupport V2，具体封闭契约见[阶段2规格](../en/roadmap.md)。TypeScript与Python共用夹具。V1哈希、字段和语义原样保留；V2进入原有StudyItem V2内容封装，变更后产生新的contentHash，不迁移历史。

candidate/disputed、题面与任务不一致、条件缺失或已知泛化问题保留可读但不能评分。verified只是来源审核声明，不是技术校验证明教学质量，真实来源与内容仍需核验。引用只能指向本题已有来源和要点；补练不能递归、不能运行时自由生成。词汇不得以V2课程配置绕过原始资格。

## 兼容、授权与回退

旧客户端按已有未知版本拒绝机制明确显示配置不可用；不丢弃新字段冒充V1。仅匹配客户端可练新内容。未自动生成正式来源、修改Obsidian或发布Companion。2A不改任何成绩、调度或数据库。回退V2读者可停用新来源，保留原来源、原答案与历史；旧V1继续原有能力。

## 检查

五类能力示例；结构边界、错引用、重复选项、审核状态、条件和题面绑定；StudyItem封装及旧哈希；词汇拒绝；Node/Python共同夹具及完整检查。结构通过不算语义判题或用户试用通过。
