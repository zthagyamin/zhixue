# ADR-022：编程执行证据与计算支持的增量版本

状态：阶段3实施前兼容方案，2026-10-08。

## 问题

现有 Python Worker 用异常字符串识别断言和测试定义问题，内容可影响归因；自动插入导入行后未提供用户代码位置映射。旧计算支持为严格 V1，不能混入步骤/提示字段。既有原始答案、首轮正式结果和补练侧车已有独立身份，不另造平行成绩系统。

## 决策

- 新执行报告独立为 CodeRunReportV1。可信执行辅助层提供阶段、异常类型、来源位置和案例结果，Worker/沙箱/客户端校验封闭、有限字段。无可信元数据保持未知，不从文本猜归因。
- 保留旧测试脚本及其执行断言计数；新增结构化函数案例每次只调用一次，失败实际值来自该次执行，不重放用户代码。自动导入前缀显式映射回原始代码。
- 计算支持新增 V2，保持 V1 字段与含义不变。可选步骤独立诊断，正式成绩只沿用最终结果。可信变式映射绑定原题和模板版本，无映射时原题重试。
- 新判题请求由应用服务绑定用户、资料库、作答和来源版本，并解析权威参考。插件只提交交互意图；既有正式事件写入与调度权威层不改变。
- 执行、步骤和变式证据通过现有作答生命周期和受控端口增量保存。原答案、提示、补练、待核对及正式事件继续隔离，后续核对采用现有版本校验/幂等与正式结果冲突保护。
- 现有 V1 checkpoint 的 pluginFields 是严格白名单，单值32KB、总值64KB；新增执行/步骤/变式及恢复指针使用独立版本侧车，不向旧 checkpoint 混入未知字段，不通过扩大旧限额使检查变绿。缺少新侧车能力时明确不可用并保留答案。

## 兼容与回退

新增字段/协议按独立版本读取，未知版本明确能力限制。旧题和旧客户端不被强制迁移，不把未知降级成答错/答对/自评。旧客户端可保留已保存答案，但不宣称具备新诊断或变式能力。

不改 StudyEventV3、FSRS、历史成绩或词汇含义，不放宽 Python 沙箱权限与资源边界。回退匹配代码和读取器，保留新增侧车证据、原来源版本与已保存答案；不删除或转换正式历史。新增持久化结构须补权限、生命周期、删除与重放说明及独立审查后集成。

## 验证与交付门槛

先复现后实现；异常类型/来源、0/1/3导入行、单次调用、协议白名单、原题版本映射与补练不覆盖首轮有行为回归。提交前完整 npm test，相关 Python/跨语言检查；公开边界按 CONTRIBUTING 独立审查。真实手机、本人、材料和时间效果最后统一验收，不由工程结果代替。
