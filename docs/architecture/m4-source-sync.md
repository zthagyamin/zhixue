# M4 来源与同步边界

候选实现从 M3 提交 `104e51512b2a18a36b563ec591dc2254981961af` 接续。设计见 ADR-007；本说明不代表已合并或部署。

## 模块与入口

| 位置 | 职责 |
| --- | --- |
| `src/domain/sync` | 严格记录/摘要/提交契约、哈希、回执归属及单调性、旧版进度转换 |
| `src/application/sync` | 原提交持久化与重建、独立目标发送、账号批次、手动/后台同步、旧版初始化与显式迁移 |
| `src/domain/sources` | 账号身份、读取状态、来源版本比较、本机来源可用性 |
| `src/application/sources` | 来源读取/冻结、配对、切换、授权连接、资料审批、导出/清理、退出 |
| `src/features/sources` / `sync` | React 生命周期、轮询/online/visibility 触发、操作锁与迟到结果控制 |
| `src/infrastructure/sources` / `sync` | HTTP、取消和超时，包括响应体解码；保持新旧协议的不同回执口径 |
| `app/study-dashboard/*-adapter.ts` | 连接原有数据库、账号客户端、进度投影；不另建 outbox 或记录格式 |

旧 app 导入路径继续转导出。Dashboard 保留页面状态与装配，不再拥有来源/传输的重试循环和回执判定。`sourcesModel` 分成 appearance、connection、catalog、sync、recovery、navigation；来源视图不能直接改同步 ref、本机 session 或题组重置状态。

## 后续更新必须遵守

1. **捕获范围后再等待。** 用户、库、模式、连接和请求代次按用例需要绑定，不能统一绑到任意 React 对象。配对不因云题库加载而取消；旧版账号进度初始化不因来源模式变化而丢失；退出不因能力元数据刷新而取消。
2. **可见内容与已保存事实分开。** 活跃题面和进度冻结，新来源暂存。旧请求可记录原事件真实回执，但不得覆盖新题、新账号的状态，或用旧 finally 清掉新请求的忙碌状态。
3. **换库先准备后提交。** `prepareLibraryAdoption` 返回同步提交闭包；等待中出现新输入、保存或身份变化，就保留原客户端库绑定和页面。不能先切客户端，再决定保留旧题面。
4. **草稿版本不等于渲染次数。** `getMutationVersion` 在每次成功编辑更新；已脏答案继续编辑也能撤销旧切换意图。`getSnapshot` 仍只用于已有展示订阅，不能用它判定是否发生新编辑。
5. **发送原记录。** 重试使用提交日志中的冻结题目、用户、库与事件；辅助摘要等待原事件真实接收。云端与本机回执独立，pending/received/applied 不得混称，旧回执不得降级已证明的 applied。
6. **取消不会撤销远端事实。** 已提交的审批、记录或授权仍可能完成；页面失效后停止后续步骤并拒绝晚到展示，不制造反向写入。
7. **清理仅接受可重建视图端口。** 用例没有删除不可变历史的入口。导出不完整只报告 partial；待上传/待恢复不完整时拒绝清理，检查过程中出现新作答也停止后续清理。
8. **退出绑定原连接。** 可选本机撤销最多等待两秒；响应体或 transport 不响应取消也不能无限阻塞。撤销和清空都绑定捕获的连接，不能清掉后来建立的新配对。
9. **审批状态属于连接生命周期。** 更换连接时清理旧列表和忙碌显示；旧审批 finally 不能解除新审批的锁。

## 验证方法与边界

- `npm test`：架构、发布一致性、lint、类型、生产构建、全部 Node 回归。原 Dashboard 断言改接实际公开用例和真实适配器，不能复制业务规则到测试夹具。
- `npm run test:python`：完整 Companion Python 回归，报告跳过项。
- CI 保留全部原浏览器套件，并新增 `.github/source-sync-browser.mjs` 的 40 个场景：10 类行为 × 桌面/390px × 浅/深主题。
- 新浏览器场景使用实际 hooks 和用例；网络、身份与记录为隔离的合成资料。原完整页面场景仍在原套件中保留。截图检查与 CI 结果须核对同一提交树。

这些检查不证明真实模型准确率、学习收益或真实跨设备资料已同步。源码没有改变用户安装的 Companion，不自动发布网站，也不把历史测试结果当成本候选的执行结果。

## 回滚

M4 没有持久数据迁移。需将用例、hook、装配和兼容转导出作为同一组回滚，保留原有数据库、快照、不可变事件、辅助摘要和提交日志。不得通过清空存储、强推或回退 main 来回滚候选代码。
