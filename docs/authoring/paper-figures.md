# 登记论文图表

首版支持学习库内明确登记的 PNG/JPEG，以及原始 PDF 的页内区域。图表不会从任意 PDF 自动识别；Notion 和临时上传文件暂不提供来源资产读取。图表不产生学习成绩。

在原文旁创建 `<原文文件名>.figures.json`，例如 `论文/paper.pdf.figures.json`。图片路径相对于当前学习库，PDF 路径必须是原文 PDF 本身。使用文件原始字节的 SHA-256（小写十六进制）；`sourceVersion` 对应原文，`assetVersion` 对应图片或 PDF。

```json
{
  "schemaVersion": 1,
  "sourceVersion": "原文文件的64位SHA256",
  "figures": [
    {
      "assetId": "figure-1",
      "label": "Figure 1",
      "title": "网络结构",
      "caption": "根据原始图注填写；允许多行说明。",
      "kind": "pdf",
      "path": "论文/paper.pdf",
      "assetVersion": "PDF文件的64位SHA256",
      "page": 3,
      "region": { "x": 0.1, "y": 0.2, "width": 0.8, "height": 0.4 }
    }
  ]
}
```

示例中的哈希占位符必须替换为真实值。`assetId` 为稳定的字母、数字、下划线或连字符，最多80字符；同一材料内 ID 和 label 不重复。图片使用 `kind: "image"`、PNG/JPEG 的路径和哈希，省略 `page`。可选 `region` 是完成 PDF 原有页面旋转之后、从左上角起算的 0–1 归一化坐标；省略时显示整页/整图。裁切不改变原始资产身份。

最多64个图表，登记文件350 KB、原文/PDF 20 MB且最多200页、图片5 MB且不超过8192边长/1200万像素。网页将 PDF 渲染限制在300万像素，并将展示画布最长边缩至1600。打开图表时重新核对来源及资产哈希；关闭或切换时取消请求并释放渲染资源，不提供离线图片缓存。

重新从论文资料库读取原文后，点击正文中的已登记 `Fig. 1` / `Figure 1` / `Figure 2(a)` / `Table 2` 或图表清单。未登记引用和行内代码保持普通文本。桌面支持固定/解除固定，窄屏显示可关闭的底部对照区。来源变化、图片丢失、旧 Companion 或离线时明确显示不可用；登记文件无效不阻断正文读取。

旧论文没有图表字段时不添加默认空数组，旧草稿指纹保持不变。登记或更新图表后产生新的材料指纹；旧草稿保留，需由读者核对后继续。
