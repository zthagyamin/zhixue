# 结构化回忆题（v1.26.0）

在已登记为 recall 的来源表格中增加可选 `学习配置` 列，单元格填写一个 JSON 对象；旧表格不需迁移。不要把该字段塞进词卡五列表格或旧题目字符串字段。例：

```json
{"schemaVersion":1,"type":"recall","criteria":[{"id":"cause","text":"解释原因","weight":2,"mandatory":true},{"id":"boundary","text":"说明边界","weight":1}],"hints":["先想原因","从原因、过程到结果组织","完整参考：解释原因，并说明边界。"]}
```

criteria 为 1–24 项，ID 必须唯一（ASCII 字母、数字、冒号、下划线、点或连字符，最多64字符）；文字最多1500字符；weight 默认1，允许1–1000正整数；mandatory 默认false。hints 若提供必须恰好3项，每项1–2000字符。两者至少提供一个；表格配置单元格上限16000字符。ID 稳定代表同一核对要点，改变配置会改变内容版本。

AI 只建议哪些来源 ID 被回答覆盖，程序计算权重；自评可修正该建议。没有 criteria 的题不显示伪造覆盖率。L1方向不限制评级，L2结构最高hard，L3完整参考again；该限制只使用作答前展示记录。提交后对照不会降低本次评级。

同步要求网页与 Companion 均支持 v1.26.0 新内容；升级后重新同步来源。旧 Companion 无法接收 v2 辅助摘要时，核心作答与待同步辅助记录分开保留。不要删除浏览器学习数据来“重置”提示；重置会丢失本机未同步记录。
