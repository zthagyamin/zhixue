# 数理题配置

在计算题来源表的“学习配置”列填写以下 JSON（单行）。账号题库使用 schemaVersion 2，learningSupport 使用下列对象；旧题目无需改写。

```json
{"schemaVersion":1,"type":"calculation","mode":"symbolic","domain":"real","variables":["x"],"exploration":{"expression":"x^2","parameters":[{"id":"x","label":"参数 x","min":"-2","max":"2","step":"0.1","defaultValue":"1"}]}}
```

例如题干“展开 (x+1)^2”，参考答案 `(x+1)^2`，提交 `x^2+2*x+1` 会判为等价。滑动参数只展示 `x^2` 的数值，不会给这道符号题代入参数判分。

支持显式乘号 `*`、四则运算、括号、整数幂（-8 至 8）、最多四个单字母实数变量，以及常数 `sqrt` 和部分 `sin` / `cos` 表达式。输入不超过 512 字符、128 个 token，展开项和计算量另有上限。变量作分母、变量根式、零底数或可能为零的底数的零次幂均保守降级。不会执行输入代码或按抽样值猜测等价。

数值题使用 `mode: "numeric"`；可用字符串 `tolerance: "0.000001"` 设置容差，默认 0.000001。判据为差值不超过 `tolerance * max(1, abs(参考值))`，零容差要求精确一致。超过精度预算时返回暂不能判定。参数边界、步长及容差均使用十进制字符串，避免内容版本哈希中的浮点差异。

“暂不能判定”不会调用评分或改变 FSRS；可以修改表达式重试或返回来源核对。旧 Companion 无法读取新配置时需更新安装包，不应把解析或网络失败视为已完成学习。
