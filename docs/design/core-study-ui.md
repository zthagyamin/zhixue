# 核心学习页界面规范

适用范围：`StudySessionShell` 承载的题目、作答、反馈与继续流程。本文依据现有页面和组件整理；不改变题库、正式作答事件或本机 Obsidian 的职责。

## 信息层级

1. 题目和当前作答控件组成主阅读列，桌面最大宽度 800px；代码允许在自身容器内横向滚动，正文不裁切。
2. 学科、任务范围、题型和进度在顶部提供定位。来源、题组清单与学习选项是辅助信息，按需打开；桌面题组清单可收起，窄屏沿用原生对话框。
3. 作答后反馈紧接选项或输入框，继续按钮留在反馈内。保存失败和内容变化提示始终可见，不用装饰元素替代信息。

## 视觉令牌

| 用途 | 规则 |
| --- | --- |
| 颜色 | 沿用 `tokens.css` 的 `--study-paper`、`--study-surface`、`--study-ink`、`--study-muted`、`--study-rule`、`--study-accent-*`、`--study-danger`，明暗主题共用语义。 |
| 字体 | 沿用全站 Geist Sans、苹方和微软雅黑回退；代码沿用等宽字体。短题为 22–26px，超过 100 字的长题为桌面 20px、窄屏 18px，正文和输入保持至少 16px。 |
| 间距 | 主内容用 20–32px 内边距，工具间隔 4–16px，题目与作答间隔约 24px；以 `study-core-ui.css` 的集中规则实现。 |
| 圆角 | 控件使用现有 `--study-control-radius` 8px；侧栏局部使用 12px。避免不同题型各造一套卡片样式。 |
| 状态 | 按钮保留 hover、focus-visible、disabled；侧栏按钮暴露展开状态，关闭后焦点回到触发按钮。错误文本使用语义色且保留文本说明；加载态不假装已保存。 |

## 验收边界

桌面与 390px 窄屏均检查长中文题目、English 标识符、数学符号、代码、长反馈、加载和错误状态；检查题组清单开合、键盘作答、提交与继续。隔离验收题不写真实学习记录，浏览器截图只能证明可见交互和布局，不能证明个人学习成绩或 Obsidian 写回。
