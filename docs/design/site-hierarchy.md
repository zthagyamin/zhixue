# 知学全站视觉层级

本次范围由用户确认：全站统一，包括首页、今日、学科入口、作答、设置和进度。保留现有组件、业务行为、真实内容、学习记录及本地 Obsidian 的职责；不增加依赖。

## 视觉职责

| 页面 | 第一重点 | 次级信息 |
| --- | --- | --- |
| 首页 | 产品用途、进入学习的主入口 | 功能示例、原理、安装说明；保留静态演示说明 |
| 今日 | 当前待完成的一组和继续按钮 | 入门说明、安排详情、自由练习入口 |
| 学科 | 分类标题、可进入的学科 | 材料、搜索、分类调整 |
| 作答 | 来源、题目、回答、提交和反馈 | 学习选项、来源与清单按需展开 |
| 设置 | 当前分类、当前可执行操作 | 分类说明、连接状态、维护信息 |
| 进度 | 当前范围内的真实学习结果 | 带限定说明的预测、记录明细 |

用户于 2026-10-04 明确将松绿方向改为白底、浅灰分区和蓝色强调。白色用于阅读与操作，浅灰用于章节与辅助区；蓝色集中在主要行动、选中项、焦点与少量数据强调。首页首屏和页尾也采用中性表面，不把大面积绿色替换成大面积蓝色。危险、警告、正确状态仍分别使用语义状态色，普通选项样式不覆盖它们。

当前结构取舍与审查依据见 [蓝白 UI 深入审查](../open-source.md)。这份规范表达当前学习工具的设计判断，不声称普遍最优审美或已经完成用户研究。

## 规范与实现入口

- 颜色的唯一语义入口为 `app/tokens.css`。正文、辅助文字、强调文字在阅读背景上至少 4.5:1；输入边界至少 3:1。测试为 `tests/visual-palette.test.mjs`。
- 沿用项目字体与字号体系；题干使用清晰标题，长阅读正文使用正常字重与 1.85 行高。代码沿用 CodeMirror，公式沿用现有渲染器。
- 间距按页面职责设置：相关控件紧邻，同级章节用标题、间距与分隔线区分。常规控件约 6–8px 圆角，独立任务约 10–12px；设置章节和进度摘要不再各套一张圆角卡。
- 当前导航同时使用底色、文字和边线强调；按钮保留 hover、disabled、focus-visible 状态。减少动态效果的系统偏好仍被尊重。
- 手机设置导航和首页练习选择条允许自身横向滚动，保留可见滚动条和焦点。长公式与代码仅在自己的阅读区滚动，正文自然换行；不得裁切正文来掩盖溢出。作答区包含长题、代码或回忆输入时顶部对齐。
- 入门提示默认呈现一行原生可展开摘要，新手教学和收起仍可达；展开后保留完整说明。任务标题与估时不再限制两行。设置导航只视觉隐藏与右侧重复的描述，辅助技术仍可读，唯一说明和错误不得隐藏。
- `app/site-hierarchy.css` 管今日、学科和作答；`app/landing-hierarchy.css` 管首页；`app/settings-progress-hierarchy.css` 管设置和进度。样式限定在对应页面根节点，不引入业务状态。

后续组件应复用语义颜色和现有结构。样式覆盖层是当前兼容入口；替换原组件时同步移除被替代规则，避免继续积累相互竞争的覆盖。验收证据见 [本次验收](../open-source.md)。
