# 学习质量验证：工程、语义与延迟表现分开

## 当前证据边界

EDU-C 内置四个基础代数模板，全部是页面临时练习。规则、参数域、解的类型与局部变形一起定义题目；不把任意旧题乘倍数当作新题，不用随机代入宣称证明。是否适合当前课程，由用户在打开时确认。内置模板经过确定性工程核对和公开教材对照，不宣称教师已人工审定。

| 模板 | 参数域 | 解的边界 | 题族 |
| --- | --- | --- | --- |
| 约除条件 | k 为 −8…8 整数；是否已给 x≠0 | 包含零时不能直接同除 x；已排除零时允许，即使原式无解 | zero-and-division |
| 平方根符号 | 给定整数 x∈[−9,9] | 主平方根为非负值；负数/零/正数分别检查 | principal-root |
| 线性新情境 | 正变化率 1…8；初值 0…12；目标 12…40 | 精确分数；初值为零时直接相除也合法；零时长合法 | affine-equations |
| 反求系数 | 代入点 −8…8；常数 −12…12；目标 −20…20 | 系数非零时唯一解；零系数区分矛盾和任意实数 | affine-equations |

规则依据：[等式的除法性质](https://openstax.org/books/elementary-algebra-2e/pages/2-2-solve-equations-using-the-division-and-multiplication-properties-of-equality)、[一元方程与解的分类](https://openstax.org/books/college-algebra-2e/pages/2-2-linear-equations-in-one-variable)、[主根与根式](https://openstax.org/books/intermediate-algebra-2e/pages/8-1-simplify-expressions-with-roots)。题干和参数为项目自建样例，不复制教材习题。

## 可重复的开发验证

```sh
node --experimental-strip-types scripts/evaluate-guided-math.mjs report.json
```

输入是 `tests/fixtures/guided-math-v1.json`。输出每例最终结果、步骤状态、预期匹配、确定性覆盖和 unknown，并报告总样本及关键错误分母。已有样例用于开发，不是未见保留集。零关键误接受只能陈述“在这批样例中未见”，不能外推为零错误系统。

无解、不唯一、合法替代方法、定义域限制、非法除零、最终值正确但步骤错误、未知函数都有明确样例。平方根的最终结果是给定数值；可选局部步骤明确推广到所有负实数或所有非负实数，不能只用某一个点偶然相等来证明。与已有数学内核的 Node/Python 共同夹具回归一起运行；新网页原型没有新增跨端正式评分协议。

## 保留集与长期试用

`assertSeparatedFamilies` 同时检查模板题族和父题身份在 development / holdout 之间无交叉；不能仅换随机种子当成独立题。线性新情境和反求系数归入同一题族。看过或调参使用过的保留题必须移到开发集，并重新准备未见材料。

当前人工语义审定样本、未见保留样本、真实模型调用和延迟学习测量均为 0，脚本如实输出 0。后续由明确批准的小规模试用收集：原题家族、来源版本、先验熟悉度、实际间隔、辅助使用、跳过/缺席和总耗时。不得用点击、预览、Agent 作答或本轮即时重练推断掌握。

延迟表现按“有效独立测验次数”作分母，同时报告受辅助、缺席与跳过；网页只能记录本页行为和自报，无法证明用户没有使用其他应用。安排复测仍走既有计划确认，不自动增加负担。小样本仅支持个人产品改进，不声称普遍学习因果效果。
