# 长线计划、知识库映射与 AI 伴学

## 长线计划

在今日、学习进度或数据与设置页面打开「长线计划」。选择截止日期、工作日与周末时长，按学科调整优先级、新学上限、实际练习轮数及预测留存率。先预览，再保存并启用；也可以暂停后恢复，或另建目标。

长线计划使用账号题库，或支持任务计划的本机固定索引知识库。旧版本机学习模式保留原有计划，不会因为确认资料映射而自动迁移；映射内容可以进入账号题库使用长线计划。AI 侧栏也可独立用于已连接的旧版本机学习库。

新目标从明天开始。手动调整保留今天和历史安排；自动重排只有在已核对今日计划、当天没有草稿、批准安排或作答活动时，才会更新这个尚未开始的学习日。容量不足的内容单独列出；延长日期或增加时长只是可选方案，不会自行更改目标。

初学完成、真实练习和正式掌握有不同证据要求。预测假设后续复习均回答 Good，使用同一个 FSRS 模型；预测留存率仅改变未来负荷估算，不改真实卡片或到期日。已有记录的统计标注了排期核对日期。来源版本不明或证据不足时保留待核对项，不推定完成。

## 知识库映射与入门包

数据与设置中的「资料结构映射」可通过已连接的 Companion 检测文件夹、PARA 或 frontmatter 结构。检测结果是候选，预览并确认规则后才登记资料。

原始笔记只读。确认后的内容使用所属账户的派生练习与状态文件；旧版来源、固定索引和已有学习记录继续保留。手动改动派生文件、路径冲突或不安全链接会停止登记并显示问题。取消映射不删除原始资料或历史记录。

「知识库入门包」提供词汇、Python 练习、概念回忆三套提示词和 Markdown 示例，也可以下载完整目录包。生成示例均标记为未练习；占位来源与状态链接需要替换并验证。

## AI 学习助手

加载学习库后可使用右侧助手。桌面支持停靠、拖动悬浮及收起；Ctrl / Cmd + `\` 切换展开状态。平板与手机使用可滚动面板。收起或查看设置保留当前未发送的问题，切换学科与题目不会重建主练习区域。

侧栏、每日计划编辑器和连接配置使用同一套模型设置。选择 DeepSeek 或 ChatGPT · OpenAI API，填写账户可用的模型 ID、API 地址和密钥，确认传输内容与 API 费用后启用。网页登录与模型 API 是不同服务，登录网站不会自动获得 API 调用权限。

账号模式将密钥加密保存在账号服务；本机模式使用系统凭据库。对话历史仅存于当前浏览器，按账号、学习库、提供商及题目对话隔离，不跨设备同步。设置、请求和历史在切换账户或学习库时重新绑定。

助手接收当前题面、已输入的尝试、代码与运行错误，不接收内部草稿标识或资料路径。提示、解释、调试和变式按钮使用统一流式回复界面，支持公式、代码高亮和复制。回复展示会加入现有辅助观察；AI 对话本身不判定作答、不增加学习轮数，也不改变正式掌握状态。

## 验证边界

自动化测试与浏览器验收使用临时资料库、隔离账号和固定模拟回复。它们验证实现与数据流；真实提供商的模型权限、余额及网络可达性，需要使用自己的 API 配置后以实际请求确认。
