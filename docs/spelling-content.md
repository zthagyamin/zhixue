# 拼写与可信拼读映射

旧词条继续使用逐字拼写，无须迁移。可在词库表格添加 `学习配置` 列，为明确核实的字母组提供音素映射；系统不猜测拼读规则。

```json
{"schemaVersion":1,"type":"spelling","word":"ship","segments":[{"letters":"sh","phoneme":"ʃ","isTricky":true},{"letters":"i","phoneme":"ɪ"},{"letters":"p","phoneme":"p"}]}
```

字段为封闭集合。`word` 必须与词条完全相同，支持 1–100 个英文字母、空格、连字符或单引号；各组 `letters` 拼接必须等于原词。每个 `phoneme` 为 1–80 个 UTF-16 单元的非空、无控制字符文本，`isTricky` 为可选布尔值。带映射的内容采用已有 StudyItem schemaVersion 2，只开放 spelling 模式；本机与账号使用相同校验和哈希。旧端不能将不支持的字段静默丢弃。

输入保持单字符后缀插入或末尾删除。IME 组合阶段暂存输入，不计错误；提交后仍只接受同样的单字符英语编辑，中文结果或整词替换不推进。粘贴、批量自动补全不代替逐字作答。桌面浏览器与事件回归已覆盖，未宣称真实手机键盘或所有 IME 均经硬件验收。

同一字母组错两次会强调该组框线，不提前显示目标字母。完成后显示来源拼读；主动查看拼读会展示答案，记录 reference-answer 并记为 again。揭示时取消未提交的完成计时器，避免先记为独立答对。临时草稿保留输入、错误及已看答案；仅限当前页面生命周期，刷新并非持久恢复。

WPM 默认关闭，按当前挂载中接受的字符数 / 5 / 输入首尾间隔计算，不足一秒显示破折号；暂停也计入该间隔，重挂载清零，不影响评分。动效可关闭，系统减少动态效果设置始终优先。
