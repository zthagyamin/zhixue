# 常见问题

[English](../en/FAQ.md) · [开始使用](getting-started.md) · [README](../../README.zh-CN.md)

## 知学是课程平台或 Obsidian 替代品吗？

不是。它为你选定的资料提供练习与复习界面。原始资料仍由本地知识库/文件夹或连接来源管理。导入材料、生成摘要或完成一轮练习，都不等于已经掌握。

## 开始前必须安装 Companion、Obsidian，或购买 AI 订阅吗？

浏览器笔记试学不需要 Companion 或 API 密钥，需要时按网站提示登录。Obsidian 是可选来源。Companion 增加支持的持续读取和本机写回；AI 功能需要单独配置 API，可能收费。ChatGPT 网页订阅不等于 API 额度。

## 所有数据都留在本地吗？

不是。笔记试学在浏览器处理所选文本，不上传、不调用 AI；其他功能各有边界。启用账号同步会传输结构化题目和学习/安排信息；API 请求会发送相关问题、上下文或回答，其中可能包含笔记提取文字。Notion 本身也是外部服务。启用前请预览来源和核对设置。

本机来源映射和本机凭据由 Companion 管理。账号模式 API 密钥另行配置，加密保存在账号服务，不是从本机凭据库自动复制。“云端安全”导出表示受限的数据契约，不代表允许字段绝不会包含个人文字。

## 能完全离线吗？支持 Mac、Linux 或手机吗？

网页支持窄屏布局，但不提供全功能离线保证。云端与 AI 需要联网，来源操作需要相应 Companion 运行。浏览器本机材料功能受设备和浏览器限制。

打包 Companion 流程面向 Windows x64，不承诺 macOS/Linux 安装器。手机和平板可使用支持的网页/账号功能，不能运行 Windows 程序，也不能直接操作另一台电脑的本地 Companion。真实手机与跨设备学习仍需更广泛验收。

## 配对成功后为什么还是示例？

安装、配对、来源登记与账号学习库启用是不同状态。在“连接你的笔记”先预览并确认一份小材料，然后核对同步状态。连接检测成功不等于已经导入目标题目。

## 为什么试学回答不见了？

笔记试学的答案与再练标记是临时页面数据。单独保存试学材料，只在当前浏览器保存题目/材料，不保存试学回答或正式成绩。换设备或清理存储前保留原文件，并使用支持的备份/导出。其他学习模式各有保存规则，请查看其状态。

## “已保存”代表已经写入知识库，并能在每台设备看到吗？

不是。本机保存、账号同步和来源写回有不同回执。排障时不要丢弃待处理记录；保留输入和备份，核对具体目的地的状态，不要反复新建资料库。

## AI 评分可靠吗？“待核对”是什么意思？

AI 可能判断错误，也可能缺少证据。无法判定或待核对不等于答对/答错。反馈应对照来源，提取错误应先修正。首轮与补练分开，补练成功不抹去首轮结果，也不证明长期保持。

## 编程和数学插件能证明什么？

编程支持当前包含的 Python 执行路径与给定案例。通过这些案例不证明代码完整正确，也不证明适合执行任意不可信程序。当前基线不承诺 C/C++ 生产执行。

数学核对有边界，包含支持的数值/符号比较和匹配的相关练习，不验证任意证明或所有表达式。不支持时可以弃权。具体实现与安全边界见[开发指南](development.md)。

## 能读取任意 PDF 或整个 Notion 工作区吗？

不能。PDF 必须可读取并符合对应导入限制；扫描件需另行 OCR，复杂分栏、公式与图表应对照原页。Notion 只读取明确授权的页面，不自动遍历整个工作区。写入记录需要另外配置位置与权限。

## 下载源码就能一键自托管全部功能吗？

目前不能保证。源码支持开发，但生产服务依赖 Sites 身份和 D1。副本不包含生产凭据，也没有开箱即用的替代身份提供商。本地模拟登录不适合公开服务。先阅读[开发指南](development.md)和实际托管前提。

## 如何反馈问题？

非安全问题可提交 [Issue](https://github.com/zthagyamin/zhixue/issues)，附版本、系统/浏览器、入口、步骤、预期/实际结果及最小合成示例。移除密钥、配对码、账号标识、私人笔记、回答和敏感路径。疑似安全漏洞按 [SECURITY.md](../../SECURITY.md)私下报告，不在普通 Issue 公开可利用细节。
