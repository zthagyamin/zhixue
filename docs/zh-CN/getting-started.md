# 开始使用知学

[English](../en/getting-started.md) · [README](../../README.zh-CN.md) · [常见问题](FAQ.md)

先用一份短小、不敏感的材料走通流程，不必一次接入全部资料。

## 1. 先在浏览器试学

打开[学习工作台](https://zhixue-daily.zthagyamin.chatgpt.site/study)，需要时按网站提示登录。完成教学或看到示例，不代表个人资料库已经连接。

展开“用自己的笔记试学”，选择 1—2 个 UTF-8 Markdown/TXT 文件（每个最多 256 KB），或粘贴一个完整段落。使用 `Q: 问题`、`A: 答案` 等明确问答文本，有助于保留任务意图。

试学在当前页面提取最多三道回忆题，不调用模型、不上传所选文本、不写正式学习记录。能提取出题目不代表题目质量合格，请核对是否值得练习。

先填写回答，再点击“查看原文并自评”。仍不熟悉的题可以标记再练，熟悉的题继续。结束后按需只练标记题。

试学答案和再练标记只在本页保留，离开或刷新后不保留。完成后需要下次再开，可单独保存材料；保存的材料留在当前浏览器，不自动进入 Obsidian、账号题库或正式今日计划。保留原文件，换设备前使用可用的材料备份操作。

## 2. 按需连接持续来源

持续读取本机资料和写回，已支持的打包流程使用 **Windows x64 Companion**。不必安装 Obsidian，也可以连接普通笔记文件夹。网页选择文件不等于授予 Companion 持续读取权限。

现有网站的[Companion 指南](https://zhixue-daily.zthagyamin.chatgpt.site/companion-guide)提供对应包的安装说明。本开源源码不附带认证发行包；单独提供的包应核对版本、分发说明与校验值，不要为运行安装包而关闭系统防护。

Companion 启动后：

1. 保留程序窗口，可以最小化。
2. 登录准备使用的网站账号，打开连接与设置。
3. 需要配对时，输入 Companion 当前窗口中的一次性配对码。
4. 确认网页报告本机连接已经就绪。
5. 在“连接你的笔记”选择一份小来源，预览并确认接入。

安装、配对、资料登记是三个状态。配对后仍显示示例，不代表个人资料导入成功。不要通过换账号或删除数据来修复连接。

本地笔记和可读取文件都有相应格式、体积限制；PDF 提取不是 OCR。Notion 需要明确授权所选页面，公开链接或浏览器登录不等于 API 授权。写回 Notion 时另行指定学习记录父页面及权限。

## 3. 核对可练习内容

查看来源名称、题目与参考答案。导入文档不等于已有可靠练习；模糊问题、缺失答案、提取错误和无效来源绑定应先修正。

从“今日”查看安排，从“按学科学习”自行选内容。长线计划和已经登记的学习池共同影响今日任务。学习日以配置时区的凌晨 4 点为边界，夜间记录请结合实际设置解释。

先回答，再看反馈，按需补练。首轮、受辅助尝试、补练和待核对分开保存；一轮结束不等于长期掌握。

## 4. 需要时再启用 AI

打开“AI 与 API Key 设置”，选择支持的提供商和模型，核对 API 地址与用量上限。目前包含 DeepSeek 和 OpenAI API 选项。ChatGPT 网页订阅不提供模型 API 额度。

启用前确认问题及引用上下文会发送到所选 API，调用可能收费。账号模式与本机模式密钥分开管理：账号服务加密保存其配置的密钥，本机 Companion 使用系统凭据库。不要把密钥写进聊天、笔记、截图或 Issue。

连接测试会真实调用模型，但只发送固定检查消息，不发送当前学习页面；它不能证明判题质量。无法可靠核对的练习可处于“待核对”，不应当作答错。

没有 API 密钥也可使用支持的非 AI 流程，包括笔记试学。复制伴学提示词只写入剪贴板，向其他 AI 网页发送是你的另一个操作。

## 5. 离开前查看保存状态

“已保存”“待同步”“已写回”分别描述不同目的地。浏览器草稿保存成功不等于云端同步或来源写回已经完成。

保存失败时保留页面，先复制输入，再重试。存在待处理记录时不要清除网站数据；换浏览器或设备前使用支持的导出和备份。关闭 Companion 会暂停本机操作，不会让本机与云端状态自动变成同一状态。

## 需要帮助

查看[常见问题](FAQ.md)或网站[帮助页](https://zhixue-daily.zthagyamin.chatgpt.site/help)。反馈问题时提供版本、平台、入口、复现步骤、预期与实际行为，以及最小合成示例；移除私人资料和凭据。

需要运行源码时，请阅读[开发指南](development.md)。自托管生产身份和账号服务需要额外集成，本地模拟登录不能作为生产认证。
