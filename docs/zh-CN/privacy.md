# 数据与隐私边界

[English](../en/privacy.md) · [开始使用](getting-started.md) · [常见问题](FAQ.md)

本文解释公开 1.41.1 的实现边界，不承诺任意部署、可选集成和第三方服务采用相同设置。在线账号服务、Companion、浏览器和 API 提供商是不同处理位置。

## 来源归属与权限

原始笔记、PDF 和课程材料继续由选定来源管理。连接本地 Obsidian 或文件夹不把它变成云端所有的资料库；选择 Notion 时，该来源本身已是外部服务。

只连接有权读取和处理的材料。能访问不自动等于能发给模型或公开分发。从小来源开始，查看预览，启用云端/AI 前核对权限。文件名不证明来源绑定有效。

## 各功能如何处理资料

| 功能 | 处理与保存 |
| --- | --- |
| 浏览器笔记试学 | 当前页面读取所选 Markdown/TXT 或粘贴文字，不上传、不调用 AI，提取最多三道题。答案和再练标记是临时输入，离开或刷新后不保留。 |
| 已保存试学材料 | 显式保存后在当前浏览器的作用域存储保留材料/题目，不自动同步账号或写回 Obsidian。 |
| 本机 Companion | 读取授权来源，管理本机来源映射/凭据，执行支持的写回。配置、数据库、缓存和备份是本机产物。 |
| 账号学习 | 启用的服务接收结构化题目、安排/进度和支持的不可变学习事件。题目可含从笔记提取的题干/参考文字；来源映射与账号数据职责分开。 |
| AI | 按操作需要发送问题、引用/选区/页面上下文、用户回答、代码或错误信息，由所选提供商依其条款处理。 |
| Notion | 读取明确授权页面；可选记录写回另指定父页面，来源与目的地权限分别核对。 |

可移植/“云端安全”协议限制字段与身份，不会匿名化每个允许的自由文本字段，也不保证用户没有填写敏感信息。不要把秘密放进来源或回答。

## 凭据与模型调用

本机 AI 密钥和 Notion 授权通过 Companion 使用系统凭据库。账号模式模型密钥另行配置，加密保存在账号服务。这是不同作用域，本机密钥不会自动发布为账号密钥。

存储加密不等于执行 API 请求的服务无法解密。所选 API 地址会收到认证所需密钥与请求内容；自定义地址会改变接收方，使用密钥前请核对。

AI 设置要求确认内容发送与可能费用。费用由所填密钥所属 API 账户承担，受供应商额度和速率限制。连接测试真实调用模型，但只发固定检查消息，不发当前学习页面。连接成功不证明判断准确。

复制伴学提示词只写剪贴板，不直接向模型发送。如果另行粘贴到其他服务，先核对包含的上下文，并遵守其条款。不要通过对话发送密钥或配对码。

## 身份、副本与写回

在线账号功能使用配置的身份与账号/资料库隔离。浏览器草稿、本机数据、云端副本和来源写回分别有回执。“这里已保存”不等于“所有位置都写好”。同一逻辑提交的重试不应重复生成正式结果。

首轮、受辅助尝试、补练、待核对与正式事件用途不同。未知评价不能包装成成绩或掌握。导出文件、同步成功本身不是学习结果。

关闭 Companion 会暂停本机读取/写回，不代表全部云端动作取消或已保存副本清除。浏览器存储绑定设备/配置文件，清理后可能丢失。换设备或删除本机数据前保留原始资料，并使用支持的恢复导出。

## 保留、删除与备份

不要从本文推断统一保留期限或完整擦除保证。不同数据保存在不同位置，第三方另有保留行为。

使用数据管理操作前检查当前功能及其作用范围。移除来源连接不证明已导入内容、云端记录、本机备份或 API 提供商副本全部删除。正式事件不可变是完整性属性，不是对法定删除权作统一声明。更广泛删除要求应覆盖实际目的地，单独设计和验证。

Companion 更新会使用本机备份保护配置与学习数据；更新或移除来源后，备份仍可能保留敏感内容。备份与导出视为私人文件，不附到公开 Issue。

## 哪些可以进入公开仓库

公开源码包含项目原创代码、经审查配置模板、文档、测试和有权公开的合成示例，不包含凭据、配对码、私人知识库、学习记录、本地数据库、账号标识、敏感路径及未去敏的日志/截图。干净导入不公开私有开发分支和历史。

第三方资产和导入材料保留各自权利。Git 外下载的构建输入不自动获准公开再分发，见[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 安全反馈

优先提供最小合成复现。文本和图片移除材料、答案、标识、来源路径、Token、配对码和密钥，文件名、浏览器及页面细节也须检查。不要公开数据库或完整恢复包。

非安全问题提交普通 [Issue](https://github.com/zthagyamin/zhixue/issues)，疑似漏洞按 [SECURITY.md](../../SECURITY.md)处理。源码公开不认证所有配置，也不能替代实际部署的安全审查。
