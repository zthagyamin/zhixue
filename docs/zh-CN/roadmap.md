# 路线图

[English](../en/roadmap.md) · [README](../../README.zh-CN.md) · [贡献指南](../../CONTRIBUTING.zh-CN.md)

路线图区分工程实现与用户验收，是公开测试版的方向，不是日期或服务等级承诺。具体提案通过 [Issues](https://github.com/zthagyamin/zhixue/issues) 和 PR 跟踪。

## 当前基线：1.41.1

源码包含每日规划/复习、词汇模式、连接来源、账号隔离同步，以及区分首答、受辅助尝试、补练与待核对的非词汇学习流程。

课程练习工程包含具体且有来源的回忆任务、结构化选择题、详细反馈、原页补练及恢复。编程/计算工程包含执行归因、公开案例反馈、原页修正、可选步骤核对、映射的相关练习及公式/长内容展示。

这些表示已有实现，不代表任意真实材料、API 提供商、设备和学习效果全部通过验收。公开源码准备及其测试回执，与此前私有开发检查分别报告。

## 下一步：论文学习与非词汇闪卡

已提交基线已有论文阅读工具和闪卡，下一阶段主要改善学习体验：

- 论文以一段或一节为中心：明确目标、阅读、回答具体问题、核对来源、继续。
- 展示可靠论文身份与定位，提供原页核对，提取错误不隐藏。
- 论文回忆以方法理解与应用为主，实验依据在必要时补充。
- 整篇整理与审稿按需展开，不争抢当前阅读任务。
- 非词汇闪卡一张只考一个知识点，忘记后可查看要点、收起再练。
- 临时补练与经过来源审核、明确加入正式复习分开。

本阶段属于拟改进工作。未提交原型不在公开 1.41.1 基线内，不标记为已交付。单词插件行为不在此次改进范围。

## 真实材料验收

使用具备必要权限的代表性课程笔记、论文、编程题和数学题，实际检查问题价值、来源一致性、反馈质量、恢复与续学。

验收证据包括：

1. 正确、部分正确、错误和无法判断/待核对。
2. 提示、揭示原文、重试、跳过、暂停、刷新和返回。
3. 提供商失败/迟到时不伪造成绩、不重复记记录。
4. 桌面、真实手机、键盘/输入及相关跨设备路径。
5. 长中文/英文、公式、代码和长反馈。
6. 用户试用反馈与耗时估算校准。

每组以 10—15 分钟为一般目标，支持暂停续学；实际时长须测量。测试夹具通过、一轮完成与长期保持改善是不同结果。

## 可维护性与贡献者入口

继续逐步迁移模块化单体，保留已有行为。领域规则纯化、使用受控 ports，不继续扩大旧控制器。改进公开设置的可复现性、文档、第三方声明和有效合成示例。

跨供应商生产自托管、非 Windows 安装器和更广泛二进制分发，需要另外设计、安全/兼容核对与验收，源码公开本身不构成承诺。

## 如何提出改进

描述学习任务、当前阻碍、最小有效改动、保留的数据边界和可观察验收条件。优先提供合成示例或有权分享的材料。遵守[贡献指南](../../CONTRIBUTING.zh-CN.md)，疑似漏洞按 [SECURITY.md](../../SECURITY.md)报告。
