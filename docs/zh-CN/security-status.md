# 安全与依赖维护状态

首次公开的 1.41.1 源码是测试版，不是生产安全认证。

对继承的锁定依赖实际执行 `npm audit`，得到 **13 条高危、0 条严重等级告警**，其中多项来自开发/构建工具及间接依赖。这是包审计结果，不等于已在知学中独立验证了 13 个漏洞，也不证明官网账号可被攻破；实际影响和修复仍待审查。

公开准备没有静默升级依赖。将分支部署到互联网前，应核对最新上游公告、可达路径、兼容性和回归覆盖。私密问题按 [安全政策](../../SECURITY.md) 报告，不在公开问题中提交攻击细节或私人日志。

首次检查覆盖待公开文件与新 Git 历史的凭据检测、文档/公开边界、完整源码回归和隔离安装回归。这些不能代替模型质量、自托管环境、真实材料或学习效果验收。

后续更新记录当次依赖审计与测试结果，不能把首次准备时的告警数量沿用为最新结论。
