# 知学 Companion 安装与使用

[分步安装指南](https://zhixue-daily.zthagyamin.chatgpt.site/companion-guide) · [进入知学](https://zhixue-daily.zthagyamin.chatgpt.site/study)

Companion 在电脑上读取你选择的笔记，并完成本机写回。**支持 Windows x64；无需预装 Python、PowerShell 7 或 Obsidian。** 安装包已附带运行环境。手机、平板和 Mac 不运行这个 EXE，可使用网站支持的在线或浏览器本地功能。

## 第一次安装

1. 从知学网站下载并双击 `Zhixue-Companion-Setup.exe`。
2. 如果询问“以前是否安装过”，首次安装选“否”；有旧版则选“是”，找到包含 `server.py` 的原文件夹。
3. 等待安装检查完成。默认装在当前 Windows 用户的个人程序目录。
4. 启动后显示本机端口和配对提示。**保留启动窗口，可最小化。** 程序自动打开网站首页。点击“进入学习”或“继续学习”，登录自己的账号，在设置中输入当前窗口的一次性配对码。
5. 网页显示“已配对／本机连接已经就绪”后，进入“数据与设置 → 连接你的笔记”，先预览一份小材料，再确认接入。

安装完成、配对成功、资料接入是三个不同状态。看到公开示例，不代表个人资料已经接入。

## 已经安装过：更新

1. 下载并运行同一个最新 EXE。安装程序寻找已注册旧目录，备份后原地更新。
2. 保留原安装目录和 `data`。无需先卸载、删除数据库或重建知识库；早期便携版按提示选择原目录。
3. 新窗口启动后，回网站“检测连接”或“重新连接／立即同步”。原配对有效时无需再配对；只有会话失效时才输入新配对码。

更新备份位于 `%LOCALAPPDATA%\Zhixue Companion Backups\日期时间`。失败时安装器会尝试恢复已有程序与个人数据；保留窗口错误信息和备份，不要继续手动覆盖文件。

## 安装后怎么用

- **启动**：开始菜单搜索“知学 Companion”，或在原目录双击 `start-companion.cmd`。网页“启动已安装 Companion”也可唤起；首次可能需要确认打开本地应用。
- **Obsidian／普通目录**：在“连接你的笔记”选择目录或文件。没有知识库也可使用自动创建的独立学习空间。
- **Notion**：添加明确授权的具体页面；需要保存记录时指定独立的记录父页面。授权令牌不要填入聊天或笔记。
- **论文**：学科库 → 论文精读工坊，可选来源或上传 PDF、Markdown、TXT、JSON；保存时选择目录或已连接的 Notion 位置。
- **AI 可以稍后配置**：没有模型密钥不等于安装失败。网页账号订阅不等于模型 API 额度。
- **关闭电脑或 Companion**：暂停本机读取与写回；浏览器草稿和已启用的账号内容按各自功能保留，恢复运行后核对同步状态。

## 按现象排查

| 现象 | 下一步 |
|---|---|
| 下载文件不完整或无法打开 | 重新下载完整安装包；确认使用 Windows x64，记录具体提示。 |
| Windows 显示来源或信誉提示 | 当前包尚未代码签名。核对下载来源，不要关闭系统防护；组织策略限制时联系管理员。 |
| 窗口一闪而过／运行环境报错 | 使用最新包，保留第一条错误与出错阶段；不要先删除 data，也不必先另装 Python。 |
| 网页显示未运行 | 从开始菜单启动，保留窗口后重新检测；检查是否打开了另一份旧安装。 |
| 端口不是 43121 | 使用程序自动打开的连接网址，不要沿用旧收藏。 |
| 配对码或会话失效 | 登录原绑定账号，使用当前窗口的新配对码；不要删数据库换账号。 |
| 已配对但仍是示例 | 在“连接你的笔记”预览并确认来源，检查格式和读取提示，再立即同步。 |
| 只有 AI 不可用 | 单独核对 AI 设置，无需因此重装 Companion。 |

反馈时提供 Windows 版本、安装包版本、首次安装还是更新、出错阶段，以及去掉配对码／密钥／个人笔记后的错误信息。

## 在网站哪里更新

打开“设置与连接”，顶部 Companion 区始终显示“下载更新 Companion”。下载后运行安装包，在原目录更新，然后启动并点击“检测连接”。网页下载不等于已经完成本机更新。

## 网页连不上 Companion

先核对当前电脑是否为安装程序的 Windows 电脑。无窗口时从开始菜单或原目录的 start-companion.cmd 启动；有窗口时核对端口，并检查浏览器对当前网站的本地网络访问权限。网站设置中的“打开本机状态页”可辅助区分程序未启动、端口不符和浏览器访问限制。

网页连接 Companion 与 Companion 连接 Notion 是两个步骤：先检测并配对，再在“连接你的笔记”中授权具体 Notion 页面。Notion 默认只读，写回可稍后单独启用。

## 便携 ZIP 与旧版维护

便携 ZIP 必须**完整解压**，再运行 `install-companion.cmd` 或 `upgrade-companion.cmd`。不要在压缩包内运行，也不要只复制 EXE、单个脚本或 `server.py`。

索引命令、旧模式及历史迁移说明在 [LEGACY.md](LEGACY.md)，不是新用户安装步骤。正常安装、更新不需要运行迁移或重置脚本。
