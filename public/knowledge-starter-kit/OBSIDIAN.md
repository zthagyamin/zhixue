# Obsidian：从建库到接入知学

Obsidian 的 Vault（仓库）就是存放 Markdown 笔记及附件的本地文件夹。Obsidian 用来阅读、整理和连接笔记；知学提供练习、反馈及学习记录，两者不需要使用完全相同的界面。

## 路径一：还没有 Obsidian 知识库

1. 安装并打开 Obsidian。打开仓库管理，选择 **Create new vault**，填写名称并选自己的文档目录；或解压本入门包后，选择 **Open folder as vault** 打开 `knowledge-starter-kit` 文件夹。
2. 如果创建了空库，把入门包中的 `Starter` 和 `Templates` 文件夹复制进去。先打开 `Starter/materials/vocabulary.md` 看内容，不必安装额外插件。
3. 先保留一份示例，再写自己的小材料；模板填写完成后移入 materials。说明文档、空模板和真实学习日志不要一起当教材导入。

官方操作参考：[管理仓库](https://help.obsidian.md/manage-vaults)。界面翻译可能随版本不同，以创建新库或打开现有文件夹的功能为准。

## 路径二：已有 Obsidian 知识库

保留原目录和笔记，不必按入门包重新整理全库。先选一个主题的小目录，比如一门课的一节笔记。通过文件管理器确认它的实际位置，再在知学中选择该目录。

现有固定索引或资料映射可继续使用，不要又通过另一个入口重复导入同一份材料。先检查预览中的题目、答案和数量，再确认接入。

## 写一篇最小可用笔记

二级标题适合拆分知识点；每节用完整段落解释一个问题，避免只有术语列表。词汇或问答可直接使用入门包表格。

```markdown
# Python 函数

## return 和 print 有什么区别？
return 把结果交给调用者；print 把文字显示出来。
函数只打印而不返回结果时，调用者拿到的返回值通常是 None。
```

这段是生成示例，需核对后使用，不代表你已经学习。真实来源请填写教材标题与位置；不要编造页码。

Obsidian 内可以用 `[[Starter/materials/python]]` 链接到本包已有的 Python 示例。笔记内链接到具体标题可写 `[[笔记名#标题]]`；后者是语法示意，需替换为确实存在的笔记与标题。见[内部链接](https://help.obsidian.md/links)。不要为了接入知学伪造 stateRef 或掌握记录。

## 在知学中接入

1. 电脑启动新版 Companion，在知学登录并配对。
2. 打开「数据与设置 → 连接你的笔记」，选择笔记文件夹，填写上面确认的目录。
3. 点击预览，核对内容，再确认。Companion 读取原文并建立独立练习。
4. 在知学实际回答一题，查看保存与同步状态；回到 Obsidian 查看相关材料或记录。

## 原文与学习记录放在哪里？

- **原文**：保留在你选中的 Obsidian 目录，普通来源接入不会覆盖它。
- **练习和学习记录**：保存在 Companion 当前配置的学习空间。如果首次设置时选择已有 Vault 作为学习空间，记录会保存在该库的知学目录中；否则使用独立学习空间。
- 已有历史记录后，不要直接改学习空间或清空数据库。想读取另一份 Vault，应添加资料来源。
- 网页“已保存”、本机“已写回”及 Notion 回执是不同状态。自动化完成不代表实际掌握。

## 手机和平板怎么使用？

账号题库启用后，可以在手机和平板登录同一知学账号学习。账号 AI 设置也在网页内完成；不需要在手机上运行 Windows Companion。本机文件的读取和写回仍由运行中的电脑 Companion 执行。

Obsidian 笔记跨设备同步与知学账号题库是两件事；知学不会自动把整份 Vault 复制到手机。若要在手机 Obsidian 中阅读原文，需要另行把相应库同步到该设备。

## 第一次使用后的自查

- 能否说出“原始笔记目录”和“知学学习空间”各在哪里？
- 是否看到来自自己材料的题目，并真实回答过一次？
- 遇到待同步或待核对时，是否保留原记录而不是重复新建？

只记录真实发生的学习。每周整理方式见 WORKFLOW.md，接入问题见 TROUBLESHOOTING.md。
