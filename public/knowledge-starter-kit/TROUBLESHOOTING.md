# 常见问题

| 现象 | 检查与处理 |
|---|---|
| 找不到管理来源 | 先配对；旧版下载更新、重启，点“更新后重新检测” |
| 路径不可用 | 在文件管理器打开目录再复制完整路径；云盘先下载 |
| 没提取到内容 | 排除空目录、空模板、系统文件和扫描 PDF；先单独导入 vocabulary.md |
| 中文乱码 | 保存为 UTF-8；旧中文文件尝试 GB18030 |
| CSV 无法识别 | 参照 word/meaning 或 prompt/answer 表头，复杂内容改 Markdown |
| Python 成了回忆题 | 升级 Companion 至 1.15.1 以上，补齐初始代码和测试代码列，重新预览 |
| 预览后确认失败 | 材料或设置可能已改变，重新预览 |
| Notion 页面不可访问 | 核对具体页面授权，在本机更新授权后同步 |
| Notion 一直待核对 | 保留原目标和记录，先核对；不要清空队列或盲目新建结果页 |
| 不能改学习空间 | 已有记录时保留原空间，添加新资料目录，不删库绕过 |
| 同一题出现两次 | 核对是否重复接入，停用重复来源并保留历史 |

求助时提供操作步骤、页面提示和文件格式即可，不要提交令牌、完整私人笔记或数据库。
