# 每天学习，每周整理

## 每天
1. 先尝试回答上次留下的问题，暂时不翻答案。
2. 阅读一小段新材料，把不理解之处写成具体问题。
3. 练习 3–5 条，区分错误来自概念、条件、步骤还是词义。
4. 记下一个具体错误及下一步。知学已保存的记录不用手动重复录入。

时间少时优先回忆旧问题，不必追求收集更多材料。

## 每周

| 检查 | 处理 |
|---|---|
| 来源不明的答案 | 标待核对，补原文或暂时停用 |
| 重复接入的资料 | 核对后停用重复项，保留历史 |
| 反复出现的错误 | 拆小问题，换例子再测 |
| 只有摘要没有作答 | 增加闭卷问题，不直接标记掌握 |
| 持续同步错误 | 分别检查读取与写回状态 |

## 逐步扩展
先用一个材料目录，确实出现第二门课程后再按课程拆分。原件与整理稿分开，真实日志放 `records/`。不用提前设计复杂标签和自动化。

## 与 AI 协作
要求 AI 先检查材料和缺失，再建议题目并说明依据。一次只问一题，等你回答后再解释。结束时只总结实际答过的问题。生成计划只是建议，先明确可用时间、截止日期与先修要求，再根据真实执行调整。
